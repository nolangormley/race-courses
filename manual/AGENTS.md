# manual

Traced GPX files for events whose organizers publish the course only as a PDF or an image, at `<state>/<race>/<event>.gpx`.
An event in `../races.yaml` uses one through its `source`; the crawler reads it like any other map (`pipeline.explicit_refs`).
`README.md` says where each file comes from, how it was traced and how sure it is; add an entry with every new file.
